# 6 Royal St Terraces: royalterraces.com.au

The public website for 6 Royal Street, Toowoomba City, a TN Macartney Projects Pty Ltd development.

This is a static site with no build step. Vercel deploys every push to `main`.

Don't edit these files by hand. They're generated by `_tools/golive.mjs` in the 6 Royal St project folder from the newest reviewed website draft. Site files only: no leads or other personal information ever go in this repository.
